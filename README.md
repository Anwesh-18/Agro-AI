# 🌾 AI Crop Predictor

An AI-powered web application that predicts the most suitable crop to cultivate based on soil and environmental conditions.

This project is being built from scratch as a learning journey into Machine Learning, FastAPI and a bit of full-stack AI application development.

---

## 🚀 Project Goal

To help users determine the most appropriate crop for cultivation using machine learning models trained on agricultural data.

The application will analyze factors such as:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* pH Value
* Rainfall

and recommend the best crop for the given conditions.
